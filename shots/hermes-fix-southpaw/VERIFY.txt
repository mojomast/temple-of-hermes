Fix summary:
- Parse.HC uses numeric ASCII codes for character comparisons. The
  TinkerOS 5.20-rc10 HolyC lexer reports "Char const limited to 8 chars"
  after this file when a following include is compiled; numeric codes
  remove the offending char constants.
- View.HC and Digest.HC replace unsupported ternary expressions with
  SouthpawDft() and an explicit if/else.
- View.HC opens maximized so the digest is the visible window.
- Post text still passes through SouthpawSafeText before DocPrint; the
  fixture line with DolDoc/OSInstall text renders as inert text.
- Official art paths are unchanged. No .GR files were added or replaced.
