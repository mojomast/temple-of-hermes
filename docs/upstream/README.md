# Preserved upstream TinkerOS documentation

This directory keeps the TinkerOS-focused documentation that the
`hermes/rebrand` work does not want to lose. The files are **copies**, not
deletions (trailing whitespace normalized for repository hygiene). The
originals still exist at their old paths in the repository and, for the in-OS
documents, in `Doc/`.

## Provenance and license

These documents come from TinkerOS 5.20-rc10 (`tinkeros/TinkerOS`), which is
itself a fork of TempleOS by Terry A. Davis. TinkerOS is released under the
Unlicense; TempleOS is public domain. The Unlicense text is in the repository
root at `LICENSE`.

The copies are kept for credit, history, and offline reference. Where the
current `Doc/` page has been rebranded, this directory preserves the upstream
wording so the attribution and the original instructions are still available.
